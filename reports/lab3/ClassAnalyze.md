## Метод `MediaFile.upload()`

**Опис логіки:** Перевіряє розмір файлу на додатність. Імітує завантаження та генерує помилку мережі, якщо у назві є маркер `network_error` і розмір перевищує розмір одного чанка (5 MB).

| Вхідний параметр / Стан | Класи еквівалентності (EP) | Граничні значення (BVA) | Очікуваний результат |
| :-: | :-: | :-: | :-: |
| `file_size` (Розмір файлу) | **EP1 (Невалідний):** `file_size <= 0` | `-1`, `0` | Викидається `ValueError ("Неприпустимий розмір...")` |
|| **EP2 (Валідний):** `file_size > 0` | `1`, `5242880` (5MB), `5242881` | Успішне завантаження|
| `file_name` (Ім'я файлу) | **EP3 (Невалідний):** Містить підрядок `network_error` (за умови `file_size >= 5MB`) | Не застосовується до рядків (дискретні стани) | Викидається `ConnectionError` на етапі завантаження |
||**EP4 (Валідний):** Не містить підрядка `network_error` | Не застосовується | Успішне завантаження |

## Метод `WasmProcessor.process()`

**Опис логіки:** Перевіряє формат файлу, валідує права доступу користувача до високого бітрейту (Premium) та обробляє специфічні пошкоджені файли під час імітації процесингу.

| Вхідний параметр / Стан | Класи еквівалентності (EP) | Граничні значення (BVA) | Очікуваний результат |
| :-: | :-: | :-: | :-: |
| `file.format` (Формат) | **EP1 (Валідний):** Належить до [`"mp4"`, `"webm"`, `"avi"`, `"mov"`] | Не застосовується | Перехід до наступної перевірки |
|  | **EP2 (Невалідний):** Усі інші формати (напр. `"mp3"`, `""`) | Не застосовується | Викидається `ValueError ("Формат не підтримується")` |
| `target_bitrate` та `is_user_premium` (Бізнес-правило) | **EP3 (Валідний):** `is_premium = False`, `bitrate <= 3000` | `is_premium = False`, бітрейт: `2999`, `3000` | Перехід до процесингу |
|  | **EP4 (Невалідний):** `is_premium = False`, `bitrate > 3000` | `is_premium = False`, бітрейт: `3001` | Викидається `PermissionError ("доступний лише за Premium")` |
|  | **EP5 (Валідний):** `is_premium = True` (будь-який бітрейт) | `is_premium = True`, бітрейт: `3000`, `3001`, `9999` | Перехід до процесингу |
| `file.file_name` (Стан файлу) | **EP6 (Невалідний):** Містить підрядок `corrupt` | Не застосовується | Викидається `RuntimeError ("Виявлено биті пікселі...")` |
|  | **EP7 (Валідний):** Нормальна назва | Не застосовується | Успішна обробка, повернення Blob (байтів) |

## Метод `User.batch_process_files()`

**Опис логіки:** Оркестратор. Перевіряє статус авторизації, ітерується по списку файлів, обробляє винятки (`try-except`), щоб помилка одного файлу не зупиняла інші, і зберігає результати в історію (`HistoryRecord`).

| Вхідний параметр / Стан | Класи еквівалентності (EP) | Граничні значення (BVA) | Очікуваний результат |
| :-: | :-: | :-: | :-: |
| `is_logged_in` (Статус логіну) | **EP1 (Невалідний):** `False` | Не застосовується | Вивід повідомлення `"Спершу потрібно увійти"`, метод завершує роботу |
|  | **EP2 (Валідний):** `True` | Не застосовується | Початок пакетної обробки |
| `files` (Список файлів для обробки) | **EP3 (Пустий):** Список не містить елементів | `len(files) == 0` | Метод завершується успішно, нічого не додається в історію |
|  | **EP4 (Валідний):** Список містить лише коректні файли | `len(files) == 1`, `len(files) > 1` | Усі файли оброблені, історія поповнюється записами типу `PROCESS_SUCCESS` |
|  | **EP5 (Змішаний):** Список містить як коректні, так і проблемні файли (які викликають `ValueError`, `RuntimeError` тощо) | Не застосовується | Цикл не переривається. Валідні файли отримують статус `PROCESS_SUCCESS`, проблемні — `PROCESS_FAILED`. Всі потрапляють в історію. |
